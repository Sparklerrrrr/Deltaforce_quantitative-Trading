# 手动资讯入口

把你想喂给系统的文字（B 站视频文字稿、QQ 群消息、公告……）存成 `.txt` 或 `.md` 放进这个目录，
下次 `python -m dfq run` 时会自动入库、提炼观点，并在几天后对照真实价格给信源打分。
同一段文字只会入库一次，放着不删也没关系。本目录下的文稿不会被提交到 git。

## 写法一：文件开头写几行说明（推荐）

```
source: bili
name: moligod
title: 本周子弹怎么倒
date: 2026-11-12

（空一行后粘贴正文）
```

`source` 可选：`bili`（B 站 UP 主）、`qq`（QQ 群）、`news`（新闻公告）、`other`。
`name` 是信源的名字，信用分按它统计，所以同一个 UP 主请始终用同一个写法。

## 写法二：靠文件名

`bili_moligod_本周子弹怎么倒.txt` → 来源 bili，信源 moligod，标题“本周子弹怎么倒”。

## 写法三：命令行

```bash
python -m dfq note add --source qq --name 某交易群 --title "11月13日群聊" --file 聊天记录.txt
```

不带 `--file` 时可以直接粘贴，结束后按 Ctrl+Z 再回车。

## 提示

- 只有“提到了关注清单里的品种 + 明确看涨/看跌”的话才会被记成观点；闲聊会被忽略。
- 没开大模型时用关键词规则提炼，比较保守，会漏掉委婉的说法；开了大模型后效果更好。
- 所有信源一视同仁地打分，包括 moligod —— 他既是数据站站长又是主播，可能有利益相关。
