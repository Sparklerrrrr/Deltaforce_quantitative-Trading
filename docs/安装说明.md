# DFQ 安装说明

DFQ 是一个帮你记录子弹交易、每晚发交易计划邮件的小工具。它**不会操作游戏**，所有买卖都由你自己在游戏里完成。
需要 Windows 10 或 Windows 11（64 位）。

## 1. 下载

到项目的 GitHub 页面 → 右侧 **Releases** → 最新版本，下载安装包 `DFQ-Setup-版本号.exe`（只有这一个文件）。
页面上的说明里写着它的校验值（`SHA-256:` 后面那一长串）。

**为什么只从这里下载**：Releases 里的安装包是 GitHub 自动从公开源码构建的，说明里写明了对应哪一次提交。
别人转发的安装包可能被改过。

## 2. 核对校验值

在下载文件夹的空白处按住 Shift 点右键 →「在终端中打开」（或「在此处打开 PowerShell 窗口」），输入：

```powershell
Get-FileHash .\DFQ-Setup-1.0.1.exe -Algorithm SHA256
```

把显示的一长串字母数字和 Release 说明里 `SHA-256:` 后面的那串对比（不区分大小写）。**完全一样**才继续；不一样就删掉安装包重新下载。

**为什么要核对**：确认下载的文件没有在传输中损坏、也没有被人替换过。

## 3. 安装

1. 双击 `DFQ-Setup-版本号.exe`。Windows 可能提示「Windows 已保护你的电脑」：这是因为安装包没有购买代码签名证书，
   点「更多信息」→「仍要运行」。
2. 选择安装文件夹。默认是 `D:\DFQ`（没有 D 盘时放在你自己的程序目录）。
   - **为什么建议单独一个文件夹**：DFQ 的配置、密钥、交易记录、日志**全部只保存在这个文件夹里**，不会写到别处；
     卸载时也只清理这个文件夹。所以不能选盘符根目录、Program Files 或 Windows 目录。
3. 不需要管理员权限。

## 4. 第一次打开

1. 打开 DFQ。第一次启动会在安装文件夹里生成：
   - `config.yaml`：配置（从模板复制，没有任何人的个人设置）；
   - `.env`：密钥文件（**里面是空的**，只有说明）；
   - `data\`：交易记录数据库、日志等。
2. 在「设置」页填写你自己的小涛查 token；想收计划邮件，再填邮箱和授权码；用大模型的话填 API Key。
   - **为什么密钥放在 `.env` 里**：它只在你的电脑上，不会上传；程序的日志会把密钥打码。
   - `.env` 是明文文件：不要发给别人、不要截图、不要放进网盘的共享文件夹。
3. 想每晚自动生成计划，在「设置」页创建计划任务（只在你登录 Windows 时运行）。

如果你以前按旧说明在 Windows 的「环境变量」里设置过 `DFQ_` 开头的密钥，它会**优先于** `.env`。
想知道每个密钥实际来自哪里：在安装文件夹里打开终端运行 `.\DFQ.exe status`，结果写在 `data\logs\task-日期.log` 里
（只显示“来自 .env / 来自系统环境变量”，不显示密钥内容）。不想用旧的，就到「环境变量」里删掉它。

## 5. 升级

下载新版本安装包（同样核对校验值），先退出 DFQ（包括托盘图标），然后直接安装到**原来的文件夹**。

- 升级只替换程序文件，**不会动**你的 `config.yaml`、`.env`、交易记录和其他数据。
- **为什么要先退出**：程序运行时文件被占用，替换到一半会出问题；安装程序检测到 DFQ 在运行会提示你先关掉。
- 保险起见，升级前可以在「设置」页「导出配置」，或者把整个安装文件夹复制一份。

## 6. 卸载

在 Windows「设置 → 应用 → 已安装的应用」里找到 DFQ 卸载，或运行安装文件夹里的 `unins000.exe`。会让你选：

| 选项 | 保留 | 删除 |
|---|---|---|
| 保留配置和交易数据，删除密钥（推荐） | `config.yaml`、界面设置、`data\dfq.db`（交易记录）、计划、报告、备份 | 程序、`.env`、网站登录状态、缓存、日志 |
| 保留配置、交易数据和密钥 | 上面这些 + `.env` 和网站登录状态 | 程序、缓存、日志 |
| 完全删除 | 无 | 整个安装文件夹 |

- 无论选哪一项，都会删除这个文件夹的 DFQ 创建的计划任务和快捷方式。
- **为什么默认删除密钥**：卸载后文件夹可能被别人拿到或被你忘掉，密钥留在明文文件里不安全；交易记录留着，以后重装到同一个文件夹可以接着用。
- 卸载只会动安装文件夹里的东西；文件夹里如果有指向别处的快捷链接，只删链接本身，不会删到外面。

## 7. 装了两份？

可以把 DFQ 装到两个不同的文件夹（例如一份正式用、一份试新版本）。两份各有各的配置、密钥和数据，互不影响；
卸载其中一份不会删除另一份的数据和计划任务。注意：「应用和功能」里只显示最后安装的那一份，另一份用它文件夹里的 `unins000.exe` 卸载。

## 8. 遇到问题

- 窗口打不开：DFQ 的界面用的是 Windows 自带的 Edge WebView2。Windows 10 较旧的版本可能没有，
  到微软官网搜索 “WebView2 Runtime” 下载安装即可。
- 其他问题：在「设置」页「导出日志」，把日志包附在 GitHub Issues 里（日志里的密钥已经打码，但发之前也可以自己再看一眼）。
